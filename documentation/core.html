DocLynk Documentation

Block

This core component is intended to hold the blockchain state. This is yet to be implemented, more will be added on this component later.

Vault

Used to assign an owner to a token with a wallet address and enables encryption before token ownership is updated on the network. A vault uses a hierarchical deterministic tree to generate encryption keys for tokens assigned to a vault determined by a vault seed. The majority of a vault's function has yet to be implemented.

Token

Token contains the actual logic for changing the ownership of a token. When a token hasn't been approved to be transfered it is held in a locked state blocking the change of ownership, when a transaction is verified it becomes unlocked. Token is yet to be finished.
