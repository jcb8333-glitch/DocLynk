DocLynk Documentation

Doclynk is currently built for Unix based machines so the project and its dependendencies live in a Linux dev container.

Project Structure

All of the network and blockchain code is contained inside of the src directory. The main program file is placed inside of doclynk.cpp and all other components for the project come together in this function. The networking logic is all inside of the net directory and all of the unique functions of Doclynk live inside of the core directory. The utils directory holds header files for custom data strcuture implementations and general functions which are used in several areas of the project such as hash funtions.

Useful resources outside of src is the ops directory, this folder holds scripts to run create the kubernetes cluster on the test network (createCluster.sh) and the script to compile and run the src code (k8sBuildNet.sh).
